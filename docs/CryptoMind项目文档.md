# CryptoMind — 个人加密货币 AI 分析助手

## 一句话描述

面向普通加密货币投资者的 AI 分析助手，支持所有主流币行情分析，通过多 Agent 协作将技术指标、市场情绪、风险控制自动整合，以自然语言输出投资参考建议，降低普通用户使用技术分析的门槛。附带链上土狗币风险识别能力，帮助用户规避貔貅币、跑路盘等风险。

---

## 项目背景

普通投资者买币时面临的真实痛点：

1. **看不懂工具** — DEXTools、TradingView界面复杂，技术指标不知道什么意思
2. **时机拿不准** — 技术面和消息面信息分散，难以同时消化综合判断
3. **错过行情** — 没有及时发现价格异常或技术指标信号
4. **土狗踩雷** — 不知道合约有没有问题，不知道庄家筹码集中度，买了可能直接归零

CryptoMind 通过多 Agent 协作，将行情、指标、新闻自动整合，用大白话输出建议，让不懂技术分析的普通用户也能获得专业级的市场参考。同时支持合约地址风险识别，帮助用户在买入土狗币前规避明显风险。

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 后端框架 | Spring Boot | 主框架 |
| AI集成 | SpringAI | 多模型统一抽象、结构化输出、流式处理 |
| Agent编排 | LangGraph4J | 多Agent状态图编排、工作流管理 |
| 大模型 | DeepSeek | 量大价优，性价比高 |
| 工具协议 | MCP协议 | 标准化工具调用层，支持动态扩展 |
| 技术指标 | Ta4j | Java量化分析库，RSI/MACD/布林带 |
| 行情数据 | 币安 WebSocket/REST API | 实时行情、历史K线，完全免费 |
| 新闻数据 | CryptoPanic API | 加密货币新闻聚合，免费版够用 |
| 关系型数据库 | MySQL | 行情记录、分析历史、用户配置 |
| 缓存 | Redis | 实时行情缓存、会话上下文存储 |
| 向量数据库 | Elasticsearch 8.x | 新闻/社区内容向量化存储，同时支持语义检索+关键词检索 |
| 消息推送 | 钉钉机器人 Webhook | 支持Markdown卡片，预警推送 |

## Agent设计

### 数据Agent
- 通过MCP调用币安API获取实时行情
- 调用Ta4j计算技术指标：RSI、MACD、布林带、成交量
- 输出结构化的技术面数据

### 新闻Agent
- 从Milvus中语义检索相关新闻
- 结合CryptoPanic最新资讯
- 输出情绪判断：利多 / 利空 / 中性

### 分析Agent（核心）
- 接收数据Agent + 新闻Agent的输出
- 通过DeepSeek综合分析
- 输出结构化建议（见下方输出格式）

### 风控Agent
- 查询当前模拟仓位
- 结合分析结果给出仓位建议
- 防止过度集中持仓

### 预警Agent
- 后台定时运行（每5分钟）
- 监控价格涨跌幅、RSI超买超卖
- 触发条件时调用钉钉推送工具

## 结构化输出格式

每次分析返回标准JSON，便于展示和存档：

```json
{
  "币种": "BTC",
  "当前价格": "$85,000",
  "建议": "观望",
  "信心度": "70%",
  "技术面": "RSI=28处于超卖区间，MACD即将金叉",
  "消息面": "近期无重大利空，市场情绪中性",
  "风控提示": "当前模拟仓位60%，建议本次不超过总资金10%",
  "总结": "技术面偏多但需等待确认信号，建议观望为主"
}
```

## 多轮对话设计

用户可以进行连续追问，系统保持上下文：

```
用户：BTC现在能买吗？
系统：[分析结果] 建议观望...

用户：为什么这么说？
系统：[知道用户在追问BTC] 主要因为...

用户：那ETH呢？
系统：[切换到ETH分析] ...
```

会话上下文存储在Redis，支持多轮连续对话。

## 三条交互链路

### 链路一：用户主动问答
```
用户提问
  → 意图识别（币种、问题类型）
  → 数据Agent + 新闻Agent 并行执行
  → 分析Agent 综合输出
  → 风控Agent 补充仓位建议
  → 返回结构化结果 + 存入分析历史
```

### 链路二：系统主动预警
```
定时任务（每5分钟）
  → 检查所有监控币种
  → 触发条件：价格涨跌>5% / RSI<30 / RSI>70
  → 预警Agent 生成预警描述
  → 钉钉机器人推送Markdown卡片
```

### 链路三：简单行情查询
```
用户问："BTC现在多少钱？"
  → 直接调币安API返回
  → 不走Agent分析链路
```
